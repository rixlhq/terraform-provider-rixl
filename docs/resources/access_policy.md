# rixl_access_policy (Resource)

Manages a role-based IAM access policy with granular platform permissions in a Rixl organization.

## Example Usage

```terraform
resource "rixl_access_policy" "editor" {
  org_id      = var.rixl_org_id
  name        = "media-editor"
  description = "Grants write permissions to videos and feeds"

  permissions = [
    "video:read",
    "video:write",
    "feed:read",
    "feed:write",
  ]
}
```
